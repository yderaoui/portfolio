# HIRO — CODE:016

An animated, anime-inspired portfolio built with React and Vite.

## Local development

```sh
npm ci
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

Vercel builds the site with `npm run build` and serves `dist/`.

Artwork sources and generation notes are documented in `public/franxx/SOURCES.md` and `docs/ANIME-ARTWORK.md`.
